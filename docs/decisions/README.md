# Architecture decision records

One file per decision, numbered in the order they were taken. Numbers are never reused and files are never moved or archived; a decision that no longer holds keeps its file and gets `status: superseded` with a `superseded-by` link in its front matter. `amended-by` marks a decision that still holds except for one point, recorded in a newer ADR. New ADRs are drafted as `proposed`; only the maintainer sets `accepted` or `rejected`.

ADRs 0001 to 0009 are written in Chinese. This index gives each an English title and summary.

| ADR | Title | Status | Summary |
| --- | --- | --- | --- |
| [0001](0001-macos-runtime.md) | macOS runtime: MNN over MPS | superseded by ADR-0009 | Chose MNN over PyTorch MPS, MLX and CoreML as the first non-PyTorch runtime for Apple Silicon. Overtaken when ADR-0009 dropped local inference on macOS. |
| [0002](0002-trainer-backend.md) | KohakuMossTrainer as an external training backend | accepted | The trainer is never vendored or added as a submodule; the app clones it at runtime into `trainerRoot` and drives it as an external process with its own Python and Git environment, in a separate window. |
| [0003](0003-launcher-first.md) | No own inference engine in V1; the launcher orchestrates runtimes | superseded by ADR-0009 | Shipped a launcher around the official Python runner first, to learn from real users before building an engine. Replaced when MossInfer became the engine. |
| [0004](0004-workspaces-remote-devices.md) | Workbench, remote deployment and a global device manager | superseded by ADR-0007, ADR-0008, ADR-0009 | Instances, Cases and Jobs, SSH deployment, a device manager window and no browser web UI.
