MossStudio 2.0.0 换了一个新的创作界面：节点式画板。它把 1.0 的画布页换成一张可以连线的画板，画面、风格、起始图都是卡片。引擎按显卡自动选择，NVIDIA 之外的显卡也能用，安装与更新全部重做，并且首次提供 Linux 与 macOS 安装包。

## 创作：节点式画板

- **画面卡片**：每张「画面」是一张要生成的图。描述、尺寸、模型和 LoRA 都在卡片旁边的「生成设置」里，按不了「生成」时按钮旁边会写明原因。
- **连线**：每张卡片都有看得见的接口。把一张图的输出拖到「画面」上，就成为它的「起始图」「控制图」或「参考图」；也可以从「作品」里选图接进来。
- **「风格」节点**：一段描述加一个 LoRA。连到它的所有画面都用同一种风格，一组图不会跑偏。
- **「放大」**：把一张生成好的图重新画得更大。
- **区域**：在选中的画面上直接拖出一个框，在框上写它是「物体」「人物」还是「文字」。框总是显示文字，四角都能拉伸，右键有菜单。原来的「画框」工具取消。
- **胶片条和配方**：每张画面下方留着它的每一次运行，可以「用作起始图」。右键菜单里有现成的配方：「改一张图」「局部重绘」「按构图生成」「参考风格」「放大一张图」「一组同风格的图」。
- **起始图、遮罩、控制图、参考图**：从 1.0 的画布继承过来，现在都是画板上的卡片和连线。遮罩工具按起始图的像素尺寸保存。
- **实时状态**：排队位置、模型加载、实时预览、步数和剩余时间都在卡片上。
- **更安静的画板**：没有提示文字，不常用的设置收在「高级」里，卡片拖图片就能移动，右键菜单取代了「＋」按钮。
- **新建画板**：第一张空白画面上给出三个可以直接点的点子。
- **助手**：原来的 Agent 改成了画板助手。它的工具统一注册，聊天里会出现选择、计划和确认卡片；「自主」模式自己动手，「审批」模式等你点头。等待中的计划会在画板上先用虚线框预览。

## 模型与引擎

- **按显卡选引擎**：MossStudio 检测每块显卡，为它安装对应的 MossInfer 包，几块显卡可以各装各的。NVIDIA 显卡按驱动版本选「CUDA 13」或「CUDA 12」。
- **NVIDIA 之外的显卡**：其他显卡走「兼容模式」（Vulkan）；Linux 上装有 ROCm 7 的 AMD 显卡（gfx1100、gfx1200、gfx1201）走「AMD 原生」（HIP）。这两种引擎只能文生图，画板会收起用不了的输入并说明原因。
- **macOS**：界面可以运行，本机不能生成；首次运行时点「用另一台电脑」，接一台装有 NVIDIA 显卡的 Linux 电脑来生成。
- **档位跟着模型文件走**：INT8 和 INT4 的模型会自动用对应的档位运行，不再被按显卡一刀切地拒绝。设置里的档位说明只剩一句「Reference 最精确，High 更快。」
- **用电脑上已有的模型**：首次运行时点「已有模型文件…」，或在「模型 › 高级」里「添加整个模型文件夹」，原地登记，不复制。
- **引擎自动更新**：装好的每种引擎包都会跟着 MossInfer 的新版本更新。
- **每块显卡单独指定**：「设置 › 设备与引擎 › 高级 › 每块显卡的引擎」可以手动选包，切换时立即释放显卡内存。

## 安装与更新

- **三个平台的安装包**：Windows `MossStudio-Setup-2.0.0-x64.exe`、Linux `MossStudio-Setup-2.0.0-linux-x64.run`、macOS `.dmg`，加上各平台的便携版。
- **新的安装程序**：第一次安装问你装在哪里，之后的安装和修复都记得这个位置。发现旧版 1.0.x 时可以「继续使用」它的作品、模型和设置，或者「重新开始」。装过又卸载并保留数据的，重装时会提示「发现上次保留的数据」并接着用。
- **首次运行只问一件事**：「准备开始创作」页面显示显卡、下载大小和保存位置，点「开始下载」就同时下载引擎和推荐模型。点「先去看看」可以先进画板，进度在标题栏上；下载完成自动就绪。
- **安静的自动更新**：「自动更新」开着时，新版本在后台下载，下次打开就是新版，并提示一次「已更新到 2.0.0」。标题栏只在必须更新、刚回退、你要求重启，或者更新等了三天以上时才出声。
- **签名和回滚**：更新源经 Ed25519 签名校验，下载的每个文件都核对校验和，支持增量包和断点续传。新版本启动失败会自动回到上一个版本，并告诉你一次，可以「再试一次」；也可以在「设置 › 通知与更新」手动「回到上一个版本」。
- **卸载**：Windows 在系统的「已安装的应用」里卸载，Linux 和 macOS 在「设置 › 关于」里。默认保留作品、模型和设置。
- **安装程序遇到的几种情况**：用 `sudo` 运行 Linux 安装包会被拒绝并说明；手动挪动过安装文件夹，启动时快捷方式会自动修正；macOS 上数据所在的磁盘没接上时会问你重试、换位置还是退出。

## 界面

- 新的导航：左侧「主导航」只有「创作」「作品」「模型」，开启后多出「训练」；「活动」和「设置」在底部。
- 扁平、无边框的配色，浅色和深色主题。标题栏显示显卡和显存占用。
- 「远程主机」「训练」「局域网访问」是可选功能，在「设置 › 功能」里打开。
- 所有页面统一了按钮、状态、空状态和加载的样式；删除类操作都是红色并需要确认。
- 「活动」里的任务用画面的名字命名，和画板卡片一致。
- 窗口可以比 1280 × 760 更小；Linux 上标题栏由应用自己绘制。

## 修复

- 远程主机上的任务结束后会关闭引擎进程。以前每跑完一次就留下一个占着显存的进程，越跑越慢。
- 在任务离开队列但还没开始前取消，现在真的不会开始。
- 取消远程主机上的任务，现在是在主机上取消，而不是重启本机的所有引擎。
- GitHub 令牌和 Hugging Face 令牌一样加密保存，只写不读；旧设置文件里的明文令牌会在下次启动时迁入。
- Windows 上下载的引擎压缩包走安全解压。

## 从旧版本升级

1.0.x 的内置更新不能升级到 2.0.0，请到 Releases 页面手动下载一次安装包。安装程序会发现旧版 MossStudio，默认「继续使用」它的作品、模型和设置，不需要先卸载。从 2.0.0 起，以后的版本由应用内更新完成。

## 已知事项

- 安装包和程序尚未代码签名，第一次打开时系统可能提示来源未知。
- 「兼容模式」和「AMD 原生」引擎只能文生图，没有实时预览。
- 远程主机只运行 CUDA 引擎，暂不支持 LoRA、实时预览和控制图。
- macOS 的安装与更新在 CI 上验证过，尚未在真机上走完整流程。
