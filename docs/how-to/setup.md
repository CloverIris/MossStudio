# 安装 MossStudio 并生成第一张图

从下载安装包到第一张图，一共三步：安装、首次运行时点一次「开始下载」、在「创作」里写一句描述并点「生成」。
引擎和模型都由 MossStudio 按你的显卡自动选择和下载，下载时就可以先去看看界面；之后想改，都在「设置」里。

## 需要什么

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows x64 或 Linux x64。macOS 只能运行界面，生成要交给另一台电脑（见最后一节）。 |
| 显卡 | NVIDIA 显卡走 CUDA 引擎，功能最全。其他显卡走「兼容模式」，只能文生图。Linux 上的 AMD 显卡可以走「AMD 原生」。 |
| 磁盘 | 以首次运行页面显示的「下载约 N GB」为准，模型占大头。 |
| 网络 | 首次运行要下载引擎和模型。下载线路可以在「设置 › 网络」里改。 |

## 1. 下载安装包

到 GitHub 的 Releases 页面（<https://github.com/ShallowElec/MossStudio/releases>）下载最新版本：

| 系统 | 文件 |
| --- | --- |
| Windows | `MossStudio-Setup-<版本>-x64.exe` |
| Linux | `MossStudio-Setup-<版本>-linux-x64.run`。下载后如果不能直接运行，先 `chmod +x` 它。 |
| macOS | `MossStudio-<版本>-mac-arm64.dmg` 或 `-mac-x64.dmg` |

每个系统还有一个「便携版」（`-portable.zip` 或 `-portable.tar.gz`）：解压就能用，作品、模型和设置保存在程序旁边的 `data/` 文件夹里，不写入系统。

安装包目前没有代码签名，第一次打开时系统可能会提示来源未知，选择仍然运行即可。

## 2. 安装

双击安装包，会先出现一个「正在准备安装…」的小窗口，然后是「安装 MossStudio」窗口。

1. 「安装位置」默认在你自己的用户目录下（Windows 是 `%LOCALAPPDATA%\Programs\MossStudio`，Linux 是 `~/.local/share/MossStudio`，macOS 是 `/Applications`）。下面一行写着「需要 … · 可用 …」。想换位置就点旁边的按钮选一个文件夹；系统文件夹、磁盘根目录和空间不够的磁盘都会被拒绝，并给出原因。
2. 如果电脑上装过旧版 1.0.x，会出现「发现旧版 MossStudio」卡片，右边两个选项默认是「继续使用」（新版本直接使用这些作品、模型和设置，不复制），也可以选「重新开始」（旧数据留在原处，不会删除）。旧版装在别处时，展开「旧版装在别的位置？」去选它所在的文件夹。
3. 点「安装」。装好后窗口显示「安装完成」，MossStudio 会自动打开。macOS 上还可以勾选「打开后推出安装盘」。

出错时窗口会变成「安装没有完成」，你的作品、模型和设置不受影响；可以「查看日志」或「重试」。

## 3. 首次运行：准备开始创作

第一次打开 MossStudio 会进入「准备开始创作」页面，只问你一件事：要不要现在下载。

| 页面上的内容 | 是什么 | 为什么 |
| --- | --- | --- |
| 显卡那一行 | 检测到的显卡和显存。点「详情」能看到每块显卡会用哪个引擎、要下载多大，以及更新驱动或安装 ROCm 的建议。 | 引擎版本按显卡和驱动选，选错了跑不起来。 |
| 「下载约 N GB」 | 引擎和推荐模型加起来的大小。下面是「保存到 …」，点「更改」可以换一个模型保存位置。 | 模型是会画画的那部分，有二十多 GB，提前知道放哪里、占多大。 |
| 「开始下载」 | 同时下载引擎和模型。 | 只下载这一次，之后都在本机运行。 |

1. 先看显卡那一行。如果「详情」里有一行灰字建议你更新驱动或安装 ROCm，照做后回到这里重新打开，能换到更快的引擎。
2. 已经有 MOSS-Image 模型文件的话，点「已有模型文件…」，选中那个文件夹。成功会提示「已在原位置使用 …，不用再下载模型」；如果它不是可以直接使用的 MOSS-Image 模型，会告诉你仍需下载。
3. 点「开始下载」。标题变成「正在准备」，显示总进度、已下载大小、还要多久，下面分列「运行组件」（引擎）和模型各自的进度。
4. 不用等。点「先去看看」就能进入创作页；标题栏会多出一个「准备中 N%」的小标签，带剩余时间，点它回到这个页面。创作页上的「生成」按钮这时写着「下载完成后就能生成 · N%」。
5. 下载完成后页面自动进入创作，并提示「模型准备好了，可以生成了」。中途关掉 MossStudio 也没关系，下次打开会自己接着下。

哪一步没下完，页面会写「没有下载完：…」，按钮变成「重试」；标题栏的小标签则显示「准备没有完成」。点「稍后」会跳过这一页，以后可以在「设置 › 设备与引擎」安装引擎、在「模型」页下载模型。

没有能用的显卡时，标题是「这台电脑跑不了模型」（Mac 上是「这台 Mac 不能在本机生成」），下面是两个选择：「用另一台电脑」（连上一台有 NVIDIA 显卡的电脑，在它上面生成，见第 7 节）和「重新检测」（刚装好显卡或更新了驱动时用）。也可以「先随便看看」。

## 4. 引擎是怎么选的

MossStudio 为每块显卡自动挑一个引擎包，规则如下。也可以在「设置 › 设备与引擎 › 高级 › 每块显卡的引擎」里手动指定。

| 显卡 | 引擎 | 能做什么 |
| --- | --- | --- |
| NVIDIA，驱动够新 | 「CUDA 13」 | 全部功能：LoRA、起始图、遮罩、控制图、参考图、高清修复、采样器选择 |
| NVIDIA，驱动较旧 | 「CUDA 12」，并提示「把 NVIDIA 显卡驱动更新到 R580 或更新版本，可以使用更快的 CUDA 引擎。」 | 同上 |
| Linux 上的 AMD 显卡（gfx1100、gfx1200、gfx1201），装有 ROCm 7 | 「AMD 原生」 | 只能文生图 |
| 其他显卡（AMD 在 Windows 上、Intel、驱动太旧的 NVIDIA） | 「兼容模式」（Vulkan） | 只能文生图，速度较慢 |
| macOS | 本机不能运行引擎 | 用另一台电脑 |

CUDA 引擎对 NVIDIA 驱动的最低要求：CUDA 13 需要 Windows 580.88 或 Linux 580.65.06；CUDA 12 需要 Windows 527.41 或 Linux 525.60.13。

「兼容模式」和「AMD 原生」引擎只能用 bf16 的完整模型包；推荐模型就是这种。用这两种引擎时，创作页会收起用不了的输入，并写明「这台设备用兼容模式引擎，只能文生图」。

引擎 MossInfer 是独立的开源项目，支持的显卡、协议等细节见 <https://github.com/mossimage-cpp/mossimage.cpp>。

## 5. 第一张图

1. 左侧「主导航」点「创作」。新项目里已经有一张「画面 1」卡片，空白的卡片上列着三个可以试试的点子，比如「海边的灯塔，黄昏，暖色调」，点一下就写进描述。
2. 也可以自己在「想要什么样的画面？」里写一句。
3. 点「生成」。进度显示在卡片上，生成好的图片出现在卡片右边，并同时保存到「作品」。
4. 想再来一张，在空白处右键：「新建画面」「新建风格」「导入图片…」「从作品选择…」，或者直接用现成的配方，比如「改一张图」「放大一张图」。

「生成」按不了的时候，按钮旁边会写原因，比如「引擎未就绪」或「还没有可用的模型」，点「去模型库」就能补齐。

## 6. 之后在哪里改

全部在「设置」里，按分区找：

| 分区 | 能改什么 |
| --- | --- |
| 「通用」 | 「主题」（浅色、深色、跟随系统）、「动效」、「语言」 |
| 「设备与引擎」 | 「显卡」：多块显卡时「设为默认」或「改为自动」，右上角可「重新检测显卡」。「引擎」：「安装引擎」「检查更新」「更新」，以及「自动更新」开关。「远程主机」。「高级」：「显存模式」「性能档位」「连跑时重新加载引擎」「每块显卡的引擎」「渠道」「版本」「添加自定义引擎」「引擎目录」 |
| 「存储」 | 「数据文件夹」「模型文件夹」「作品来源」 |
| 「网络」 | Hugging Face「访问令牌（Token）」；「高级」里的「下载方式」（自动、直连、镜像）、「Hugging Face 端点」、「同时下载的文件数」、「GitHub 令牌」 |
| 「功能」 | 可选功能的开关：「远程主机」「训练」「局域网访问」，默认都关闭 |
| 「通知与更新」 | 「桌面通知」、「自动更新」、「更新渠道」（正式版、测试版）、「回到上一个版本」 |
| 「关于」 | 版本、「复制诊断信息」、「环境检查」；Linux 和 macOS 上还有「卸载 MossStudio」 |

MossStudio 自己的更新很安静：「自动更新」开着时，新版本在后台下载，「设置 › 通知与更新」里写着「X 已下载，下次打开时更新」，下次打开就是新版本，并提示一次「已更新到 X」，点「看看新内容」能看更新说明。一直不关机的话，三天后标题栏才会出现「重启以更新」；想马上换就点「现在重启」。关掉「自动更新」后，有新版本时标题栏会显示「新版本 X」，由你决定何时「下载更新」。

模型本身在「主导航 › 模型」里管理：下载模型、在「其他模型 › 自己组合」里挑选部件或「用电脑上的模型文件…」、导入 LoRA（「从电脑导入」）、换「模型文件夹」。

## 7. 用另一台电脑和训练（可选）

两项都默认关闭。第一次运行时点「用另一台电脑」会直接打开「远程主机」并弹出「添加 SSH 主机」；其他时候先到「设置 › 功能」打开对应开关，相关按钮和页面才会出现。

**远程主机**：把生成放到另一台装有 NVIDIA 显卡的 Linux 电脑上跑，适合 Mac 用户或显卡不够的电脑。到「设置 › 设备与引擎」点「添加 SSH 主机」，填「地址」「用户名」和「登录方式」（密钥、密码或无需验证），保存后会马上测试连接。然后在主机那一行点「准备引擎和模型」，引擎和模型会下载到那台电脑上，生成的图片传回本机。远程主机只运行 CUDA 引擎。

**训练**：用自己的图片训练 LoRA。开启后「主导航」多出「训练」页，第一次先点「准备训练器」，它会下载训练器并安装所需环境（需要本机有 Python 3.10 或更新版本，找不到时可在「高级」里填「Python 路径」），要几分钟。之后点「新建训练」，选好图片和底模就能开始；训练好的 LoRA 会出现在「创作」里。训练位置也可以换成一台远程主机。

## 卸载

Windows：在系统「设置 › 应用 › 已安装的应用」里找到 MossStudio，选择卸载。Linux 和 macOS：在 MossStudio 的「设置 › 关于」点「卸载 MossStudio」。便携版直接删除它所在的文件夹。

卸载默认保留作品、模型和设置，重新安装会提示「发现上次保留的数据」并继续使用；只有勾选「同时删除我的数据（作品、模型、设置）」才会删掉，且无法恢复。
